# סדנת Q-Learning במבוך לאנדרואיד

סדנה מעשית ב-Java/Android Studio לתלמידים  בתחילת דרכם בלמידת חיזוק. המבוך הקטן והדטרמיניסטי מאפשר לראות את כל רכיבי האלגוריתם בלי ספריות ML, Firebase או ממשק מסובך.

## מתווה מוצע: מפגש אחד או שניים

**מפגש 1 (75–90 דקות):** משחקים במבוך, מגדירים מצב כ"מיקום הנוכחי", פעולה, תגמול ואפיזודה; מפעילים את בסיס האקראי; משלימים את הקצאת טבלת `Q[row][col][action]` ואת בחירת הפעולה החוקית.


**מפגש 2 (75–90 דקות):** מתרגמים את *עדכון Q-learning* לקוד, מאמנים אלפי אפיזודות, משווים α/γ/ε, ומאבחנים מחזורים. מסיימים בהשוואה ל-Tic-Tac-Toe: במבוך המעבר דטרמיניסטי וקבוע; יריב הופך את הסביבה לפחות נייחת ולכן Q-learning רגיל פחות ישיר.
